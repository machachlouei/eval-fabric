# PiML Explanation Audit Example

This example demonstrates how to use `eval-fabric` to audit model interpretations generated by the [PiML-Toolbox](https://github.com/SelfExplainML/PiML-Toolbox).

## Why this is useful

Interpretable ML models (like EBMs or GAMI-Nets) provide transparency, but the *quality* and *rationality* of those explanations can still vary. This example shows how to build an automated pipeline that:

1.  Generates a local explanation for a specific prediction using PiML.
2.  Uses an **LLM Judge** to check if the explanation is intuitive and professional.
3.  Uses a **Rule-Based Judge** to ensure the explanation highlights the correct features (e.g., Median Income).

## How to run

### 1. Install Dependencies
You will need `eval-fabric` and `piml` installed in your environment.

```bash
pip install eval-fabric piml
```

### 2. Register the Bridge Evaluator
To make the `piml.explanation_generator` available, you can either add it to your python path or register it via entry points. For a quick test, you can run the evaluation script directly if you import the evaluator.

### 3. Run the Evaluation

```bash
ef run spec.yaml --dataset data.jsonl
```

### 4. Inspect Results

```bash
ef show <run_id> --traces
```

## Features Demonstrated

- **Complex Evaluator Output:** The evaluator returns a dictionary containing a prediction, a text explanation, and raw metadata.
- **Hybrid Judging:** Combining a "soft" LLM-based audit with a "hard" regex-based check.
- **ML Lifecycle Integration:** Showing how evaluation isn't just for LLMs, but also for traditional (interpretable) ML pipelines.
